Drift API Reference

All /api routes require X-User-Id, a development identity header, and membership in the requested building.

MethodPathAccessParameters and purpose
GET/healthPublicDatabase and server health.
GET/api/buildingsMemberList accessible buildings and roles.
POST/api/buildingsUserJSON name, optional address/timezone. Creates owner membership.
GET/api/buildings/:id/readingsMemberfrom, to, page, pageSize (max 100), search, sortBy, sortOrder.
POST/api/buildings/:id/readingsOwner/EditorCreate interval reading JSON.
PATCH/DELETE/api/buildings/:id/readings/:readingIdOwner/EditorEdit or remove interval reading.
GET/api/buildings/:id/summaries/:granularityMemberdaily, weekly, monthly; from, to, optional electricityRateInrPerKwh.
GET/api/buildings/comparisonMemberfrom, to, optional rate. Returns accessible building totals.
GET/api/buildings/:id/readings.csvMemberOptional from/to; downloads CSV.
POST/api/buildings/:id/readings.csvOwner/EditorJSON {csv}; validated, atomic import up to 10,000 rows.

Example request

curl -H 'X-User-Id: 1' 'http://localhost:3000/api/buildings/1/readings?page=1&pageSize=50&sortBy=periodStart&sortOrder=desc'

Example response

{"data":[{"readingId":"1","periodStart":"2026-10-01T00:00:00.000Z","generatedKwh":"1.200","consumedKwh":"0.800"}]}

Full schema and validation notes are in docs/api.md.
